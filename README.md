# Komentář k zákonu č. 217/1994 Sb., o poskytnutí jednorázové peněžní částky některým obětem nacistické perzekuce

Otevřený komentář k zákonu o jednorázové peněžní částce pro oběti nacistické perzekuce — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; preambule, oprávněné osoby, vznik a výše nároku, řízení u ČSSZ a vztah k mezinárodním závazkům.

Konsolidované znění: dokument e-Sbírky `SB-1994-00217_2014-01-01`.
